
# Code of Conduct

## Our Commitment

LocalDocks is an open-source project intended to provide a welcoming environment for developers of all experience levels.

We are committed to creating a respectful, constructive, and inclusive community.

## Expected Behavior

Contributors and community members are expected to:

- Be respectful and professional.
- Communicate constructively.
- Assume good intentions.
- Give and receive useful feedback.
- Focus discussions on the project and its technical goals.
- Respect different levels of experience and perspectives.

## Unacceptable Behavior

The following behavior is not acceptable:

- Harassment or discrimination.
- Personal attacks.
- Threats or intimidation.
- Trolling or deliberately disruptive behavior.
- Publishing private information without permission.
- Sexualized or inappropriate behavior toward other community members.
- Any behavior that would reasonably make the project unsafe or hostile for others.

## Enforcement

Project maintainers may remove, edit, or reject comments, issues, pull requests, or other contributions that violate this Code of Conduct.

Serious or repeated violations may result in temporary or permanent removal from project spaces.

## Reporting

If you experience or witness unacceptable behavior, report it privately to the project maintainers rather than escalating the situation publicly.

## Scope

This Code of Conduct applies to project repositories, issues, pull requests, discussions, and other spaces officially associated with LocalDocks.

---

This Code of Conduct is intended to establish a respectful and productive environment for everyone contributing to LocalDocks.
