# LocalDocks Privacy Policy

**Last Updated:** August 31, 2026

LocalDocks ("LocalDocks", "we", "our", or "us") is a Windows desktop application designed to help developers inspect and manage local system resources, including processes, network ports, and Windows services.

## Privacy by Design

LocalDocks is designed with a local-first architecture. The application operates entirely on the user's device and does not operate a backend server for collecting, receiving, processing, or storing user data.

LocalDocks does not collect, transmit, sell, or store user data on LocalDocks servers.

System information accessed by LocalDocks—such as running processes, network ports, sockets, services, and related local system telemetry—remains on the user's device and is processed locally solely to provide the application's functionality.

## Internet Connectivity

The core LocalDocks application does not require an internet connection for its core functionality and does not communicate with LocalDocks-operated servers.

- **GitHub Releases:** For installations distributed through GitHub, LocalDocks may use the Tauri updater to periodically check GitHub Releases for available software updates. This connection is used solely to retrieve update metadata and artifacts when a newer application version is available. It does NOT collect, upload, or transmit your LocalDocks data, system information, or telemetry. 
- **Microsoft Store:** Microsoft Store installations are distributed and updated securely through the Microsoft Store infrastructure, governed by Microsoft's policies.

## Data Storage

LocalDocks does not store application data or system information on LocalDocks-controlled servers. Data generated or accessed while using the application remains strictly on the user's device, subject to the user's own Windows system and application storage limits.

## Third-Party Services and Telemetry

LocalDocks does not use third-party analytics, advertising, tracking, cookies, accounts, cloud storage, or telemetry services within the application. We do not collect "usage data."

As noted above, GitHub infrastructure is contacted by the updater for GitHub-distributed installations when checking for software updates, and Microsoft's infrastructure is used for Microsoft Store distribution and updates. These are distinct from LocalDocks-operated servers.

## Security and Limitations

While LocalDocks is designed to safely inspect your local environment, it is a local desktop application running with the privileges of your Windows user account. It does not elevate privileges. The security of the data it accesses is inherently tied to the security of your local Windows environment.

## Changes to This Privacy Policy

We may update this Privacy Policy when LocalDocks changes or when necessary to accurately describe our practices. The latest version will be published in the repository with an updated "Last Updated" date.

## Contact

If you have questions about this Privacy Policy or LocalDocks' privacy practices, please contact us by opening an issue on the official LocalDocks GitHub repository.
